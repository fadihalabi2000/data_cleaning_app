# مدقّق بيانات المراكز الصحية

تطبيق Streamlit عربي يقرأ ملفات Excel الخام، يكتشف أخطاء التدقيق، ويصدّرها في تقارير منفصلة وشاملة. لا يعدّل ملف المصدر ولا يصحح أي قيمة تلقائياً.

## التشغيل

```powershell
python -m pip install -r requirements.txt
streamlit run app.py
```

ارفع ملفاً أو عدة ملفات، اختر نوع العيادة وراجع ربط الأعمدة، ثم شغّل التدقيق ونزّل التقرير الشامل.

## الاختبارات

```powershell
pytest -q
```
